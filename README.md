# moss-skills

> Claude Code 技能集合 - 提升 AI 辅助编程效率的自定义 Skills

## 简介

本仓库用于存储和管理 Claude Code 的自定义技能（Skills）。这些技能可以从开源社区获取，也可以在工作和学习过程中积累开发。

通过合理使用这些 Skills，可以显著提升 Claude Code 的能力，让它更好地理解和执行特定的开发任务。

## 什么是 Claude Code Skills？

Skills 是可复用的代码片段、脚本或工具，可以：
- 执行特定的开发任务
- 遵循项目特定的规范和模式
- 集成常用的工具和命令
- 实现 CI/CD、测试、代码检查等自动化流程

## 目录结构

```
.
├── README.md
├── skills/           # 自定义技能文件
│   ├── example1.sh
│   └── example2.js
└── docs/            # 技能使用文档
```

## 如何使用

### 添加 Skills

1. 在 `skills/` 目录下添加你的技能文件
2. 按照技能类型组织目录结构
3. 在对应文档中说明技能的使用方法

### 管理 Skills

- 📝 **命名规范**: 使用清晰、描述性的文件名
- 🏷️ **分类管理**: 按功能领域分类存放
- 📖 **文档说明**: 为复杂技能添加使用说明

## 技能分类

- 🚀 **开发工具**: 代码生成、重构、格式化
- 🧪 **测试相关**: 单元测试、集成测试
- 📦 **构建部署**: CI/CD、打包发布
- 🔍 **代码检查**: Linting、静态分析
- 📊 **文档生成**: API 文档、注释生成
